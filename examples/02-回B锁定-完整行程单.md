### 🎒 行前清单

**证件**：三人身份证原件一张都不能少——高铁进站、灵隐预约、酒店入住、老人免票全靠它。有老年优待证也带上。

**衣物**（10月底杭州白天15-23℃，早晚凉，**湖边和塔顶风大**）：爸妈备薄毛衣/卫衣 + 挡风外套；**围巾一定带**，护脖子很管用；**软底防滑运动鞋**，石板路多，别穿新鞋或皮鞋。

**药品**：爸妈的慢病药按3天量**多带1天份**，分装写名字；血压计（如有高血压）；创可贴、藿香正气水、肠胃药、晕车药；保温杯（景区都有热水）。

**随身**：折叠伞（杭州秋天多阵雨，还能当拐杖）、充电宝、少量现金（河坊街小摊有时不方便扫码）、一小袋零食。

**🏥 就近医院**（用不上最好）：湖滨3公里内有**浙大二院解放路院区**、**杭州市第一人民医院**，打车约10分钟。出发前用地图确认下具体入口。

两句实话：飞猪实时接口今天额度用满了，上面价格是公开渠道查的**参考价**，点进去实价可能±10%浮动，车次时刻和免票政策是准的。另外**灵隐飞来峰现在免门票但必须提前1天预约**，这是这趟唯一容易踩的坑，周五别忘。

整体节奏是每天只2-3个点：游船代步、雷峰塔坐电梯、灵隐坐电瓶车、苏堤只走南段——爸妈的腿不会累。要调哪块说一声，比如「换家酒店」「加个宋城」，我只改那块其他不动。

## 这一步体现的懒人设计

| 懒人规则 | 回复里的体现 |
|---|---|
| 回一个字母就算选定，不再确认 | 用户只回「B」，管家直接「锁定了」 |
| 照着走就行 | 精确到时段，写清每段怎么去、花多少、为什么这样安排 |
| 替用户把事想到 | 订房备注「有老人，要低楼层近电梯」；楼外楼要提前订位；标出就近医院 |
| 行前清单按人员定制 | 父母的慢病药多带 1 天份、血压计、防滑鞋、围巾 |
| 提醒时间表 | 按日期列出订票、订位、灵隐预约（满 70 岁免预约）、出发前检查 |
| 不用自己操作 | 主动存成文件，方便打印或转给父母 |
| 修改只动一处 | 「要调哪块说一声……我只改那块其他不动」 |
